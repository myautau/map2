# Карта экосистемы «Газпром нефть»

Самостоятельная реализация Figma-узла `7274:76058` на HTML, CSS и JavaScript. Бренды и их группировка уточнены по фотографии корпоративной карты.

## Запуск

Откройте `index.html` напрямую или запустите любой локальный статический сервер в этой папке.

## Взаимодействие

- Нажатие на раздел слева раскрывает или сворачивает дочерние элементы.
- Наведение подсвечивает связи выбранного узла.
- Нажатие фиксирует подсветку; повторное нажатие снимает её.
